# Повтор.

Офлайн-дневник подтягиваний, отжиманий и упражнений на пресс. Мобильное приложение
в тёмном «стеклянном» дизайне **Running** из предоставленного пользователем
`Running-Design-Kit.zip`. Исходный `theme.css` сохранён **без изменений**.

## Возможности

- Запись одного подхода: упражнение, повторения, локальная дата/время, заметка.
- Быстрые значения, счётчик +/−, подстановка последнего результата упражнения.
- Дневная цель по сумме повторений; количество подходов, упражнений и серия дней.
- История с фильтрами по упражнению и дате, редактированием и подтверждённым удалением.
  Сразу после удаления можно нажать «Вернуть» (8 секунд).
- Статистика за 7/30 дней и всё время; реальные графики, лучшие подходы, 28 дней активности.
- Таймер отдыха: автоматический или ручной старт, пауза, +30 секунд, следующий подход.
- Мятный, лавандовый и персиковый акценты исходной темы.
- Резервная копия JSON. Импорт объединяет записи по ID, не заменяя текущие настройки.
  При восстановлении повреждённого хранилища копия явно заменяет его целиком.
- PWA: установка на главный экран и работа без сети после первой полной загрузки.
- Android: Capacitor, встроенные локальные файлы, системная кнопка «Назад» и нативное
  сохранение/отправка JSON через системное меню.

**Регистрация, аккаунты, сервер, реклама и облачная синхронизация не используются.**
Демо-записи при запуске не добавляются. Значения в интерфейсе считаются только по
собственным записям пользователя.

## Быстрый запуск

Нужен Node.js **22.17+**.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:5173`. Сервер слушает `0.0.0.0`, допускает preview-хосты
Arena и не публикует исходники Android, `.git`, тесты и конфигурационные файлы.

HTML/CSS/JS работают **без фреймворка и JS-бандлера**. `npm run build` только
копирует 14 локальных файлов в `www/` и добавляет отпечаток содержимого в имя
кэша service worker. Для веб-публикации достаточно раздать `www/` статическим
сервером по HTTPS. Поддерживается размещение в подпапке. `file://` для ES modules
и service worker не подходит.

## Android APK

Нативный проект находится в `android/`, идентификатор приложения — `ru.povtor.app`.
Минимальная версия — **Android 7.0 / API 24**; compile/target SDK — **36**.
Требуется обновлённый Android System WebView **111+** (для CSS color-mix и
современных API); минимальная версия явно указана в конфигурации.

### Автоматическая сборка

Workflow **Android APK** (`.github/workflows/android.yml`) запускается при push
в рабочую ветку `arena/1a0a7d15-exercises`, при pull request и вручную.
Он параллельно проверяет веб-приложение и собирает Android:

1. Node.js 22, Java 21, Android SDK 36.
2. `npm ci`, модульные тесты, `npm run android:sync`.
3. `./gradlew --no-daemon assembleDebug lintDebug`.
4. Артефакт **povtor-android-debug** с файлом `povtor-1.0.0-debug.apk`
   и SHA-256; хранится в GitHub Actions 14 дней.

Скачать: GitHub → репозиторий → **Actions → Android APK → успешный запуск →
Artifacts → povtor-android-debug**. Распаковать архив, перенести APK на телефон
и разрешить установку из выбранного файлового менеджера/браузера.

Это **подписанная debug-сборка для тестирования**, не релиз Google Play. Кэш
Actions по возможности сохраняет одну debug-подпись между сборками, но её
постоянство не гарантировано. **Перед переустановкой обязательно экспортировать
JSON**: при смене подписи Android потребует удалить старую версию, что удалит её
локальные данные.

Для публичного релиза: открыть проект в Android Studio, выбрать
**Build → Generate Signed App Bundle / APK**, использовать собственный release
keystore, повысить `versionCode` при обновлениях. Ключи в Git не добавлять.

### Локальная сборка

Нужны **JDK 21**, Android Studio / Android SDK 36 и настроенный `ANDROID_HOME`.

```sh
npm ci
npm run android:sync
npm run android:open
# или без Android Studio:
cd android
./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
В Windows — `gradlew.bat assembleDebug`.
После изменений веб-файлов обязательно выполнять `npm run android:sync`.

## Данные и ограничения

- `localStorage`: `povtor.data.v1`; отдельно `povtor.timer.v1` для таймера.
- Android и браузер имеют **разные** хранилища. Для переноса — экспорт/импорт JSON.
- Очистка данных приложения/сайта или удаление приложения удаляет дневник.
  Автоматическое облачное резервирование Android отключено (`allowBackup=false`).
- Экспорт на Android создаёт UTF-8 JSON в кэше и открывает системное меню
  «Поделиться» — выбрать файловый менеджер/другое место и сохранить копию вне приложения.
- Импорт до 10 МБ, максимум 25 000 подходов; повторения и цель — целые 1–9999;
  заметки до 240 символов; даты от 01.01.2000 до сегодняшней. Лимит памяти
  `localStorage` браузера может наступить раньше — ошибка сохранения будет показана.
- Невалидный импорт ничего не изменяет. Повреждённое сохранение не перезаписывается
  автоматически: можно выгрузить исходный файл, восстановить копию или явно сбросить
  дневник, введя `УДАЛИТЬ`.
- Серия дней считается с сегодняшнего дня, либо со вчерашнего, если сегодня ещё нет записи.
  Несколько подходов за один день дают один день серии.
- Все даты тренировок локальные; 7/30 дней — скользящий период, включая сегодня.
  Личные рекорды считаются за всё время. График «Всё время» показывает последние
  12 месяцев, а общий объём учитывает все записи, в том числе более старые.
- Таймер считает остаток по абсолютному времени, корректно переживает сворачивание
  и перезапуск. **Системные фоновые уведомления/будильник и работа после принудительного
  закрытия не реализованы**. При возвращении в открытое приложение окончание обновится.
- PWA требует первую полную загрузку через HTTPS/localhost; Android APK работает
  офлайн с первого открытия. Внешних CDN, шрифтов и API-запросов нет.

## Проверки

```sh
npm test                         # модель, даты, валидация, кэш данных, нативные адаптеры
TZ=America/New_York npm test      # календарная логика в другой временной зоне
npx playwright install chromium
npm run test:e2e                 # UI, хранение, CRUD, таймер, JSON, офлайн, адаптивность
npm audit --audit-level=high
npm run android:sync
```

Для уже установленного Chromium: `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`.
Browser-тесты проверяют ширины 320, 360, 440 и 1000 px, клавиатуру и фокус модального
окна, защиту заметок от HTML-инъекций и конфликт записи из другой вкладки.
Нативные адаптеры проверяются с моделями bridge API; это не заменяет проверку APK
на физическом Android-устройстве.

## Структура

```text
index.html             Каркас, навигация, доступное диалоговое окно
app.js                 Сценарии, локальное хранение, таймер, маршрутизация
views.js               Экраны и шторки
icons.js               Inline SVG-иконки
platform.js            Android bridge / браузерный экспорт
domain.js             Модель, валидация, календарь, статистика (без DOM)
theme.css              Неизменённая тема из Running Design Kit
styles.css             Только дополнения к теме
icons/                 Локальные PWA/launcher-иконки
manifest.webmanifest   Установка PWA
service-worker.js      Локальный офлайн-кэш
scripts/               Сервер, копирование файлов, генерация иконок
android/               Нативный Android-проект и Gradle Wrapper
tests/                Node.js и Playwright-проверки
.github/workflows/     Автоматическая проверка и сборка APK
```

`www/`, APK, отчёты, скачанный дизайн-архив и `node_modules/` исключены из Git.
Иконки уже сгенерированы; необязательная перегенерация требует Pillow:
`python3 scripts/make-icons.py`.
